## 📚 Що я зараз активно вивчаю та практикую:
* **Робота з вимогами:** вчуся збирати, аналізувати та документувати вимоги. Тренуюсь писати **User Stories** та формулювати **Acceptance Criteria**.
* **Аналітичні фреймворки:** розбираюсь, як оцінювати якість вимог за критеріями **INVEST**, вивчаю класифікацію нефункціональних вимог (модель **FURPS+**) та основи **BACCM** (Business Analysis Core Concept Model).
* **Візуальне моделювання:** знайомлюсь зі створенням діаграм для наочного опису бізнес-процесів і логіки майбутнього продукту.
* **Stakeholder Management:** розбираю в теорії, як виявляти зацікавлених осіб, комунікувати з ними та з'ясовувати їхні справжні потреби.
* **Технічна база:** практикую написання **SQL-запитів**, вивчаю принципи побудови програмного забезпечення та етапи його життєвого циклу (SDLC).
